# 抖音净化器

按正则过滤抖音网页版弹幕的 Chrome 扩展（Manifest V3）。弹幕会实时隐藏，设置保存后立即生效，并通过 `chrome.storage.sync` 在标签页和设备间同步。

[English](README-en.md)

## 功能

- 实时过滤：使用 `MutationObserver` 监听动态新增的弹幕，滚动加载的内容也能即时处理
- 正则规则：普通文本自动按不区分大小写匹配，也支持 `/pattern/flags` 完整写法
- 过滤预览：弹窗内实时展示会被过滤的弹幕；**全文完整展示、相同弹幕自动去重**；优先使用当前页面的真实弹幕，无页面数据时使用示例弹幕
- 状态与统计：展示当前页面已过滤的弹幕数量，可单独控制总开关和弹幕过滤
- 设置同步：保存设置后立即生效，其他已打开的抖音标签页以及同一账号下的其他设备会自动同步
- 单页应用适配：抖音切页时自动重建观察器并重新扫描
- **正则生成器**：内置一个三步式正则生成工具，输入正向/反向弹幕后自动推荐屏蔽词，一键填入设置，支持深色/浅色两种主题

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `manifest.json` | 扩展清单，声明权限与注入范围 |
| `content.js` | 内容脚本，负责弹幕过滤、统计和动态监听 |
| `popup.html` | 设置弹窗界面（深色） |
| `popup.js` | 弹窗逻辑，负责读写设置和过滤效果预览 |
| `generator.html` | 正则生成器页面（支持深色/浅色） |
| `generator_app.js` | 生成器 UI 交互逻辑 |
| `generator_styles.css` | 生成器样式（深色主题） |
| `core.js` | 共享核心逻辑（正则编译、候选词推荐、匹配测试） |

## 安装

1. 打开 `chrome://extensions`（Edge 请打开 `edge://extensions`）
2. 打开右上角的"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择本项目目录
5. 打开抖音网页版 `https://www.douyin.com`

## 使用

### 基础过滤

1. 点击浏览器工具栏中的抖音净化器图标
2. 输入想要过滤的正则，例如 `广告|推广|抽奖|扫码`
3. 点击"保存设置"，过滤会立即生效

### 正则生成器

1. 点击弹窗中的「生成正则」按钮
2. 在生成器的「输入弹幕」步骤填写：
   - **正向弹幕**：想要屏蔽的弹幕内容（每行一条）
   - **反向弹幕**：白名单，允许通过的弹幕（每行一条）
3. 点击「载入弹幕」后，在「确认屏蔽词」步骤点击字符选词，系统也会给出建议词
4. 在「正则·测试」步骤预览实时匹配效果
5. 点击「填入抖音净化器设置」，生成的正则会自动写入扩展存储
6. 关闭生成器页面，回到弹窗即可查看并保存

### 正则语法

| 输入 | 含义 |
| --- | --- |
| `广告` | 匹配包含"广告"的弹幕，不区分大小写 |
| `广告\|推广` | 匹配"广告"或"推广" |
| `/广告/g` | 完整正则写法，保留指定的 flags |

- 留空表示不过滤弹幕
- 完整写法支持的 flags：`d`、`g`、`i`、`m`、`s`、`u`、`v`、`y`
- 非法正则不会匹配任何弹幕，不会影响其他过滤项


## 权限说明

- `storage`：保存并同步过滤设置
- `activeTab`：向当前标签页的抖音页面发送设置更新和统计请求

内容脚本只注入 `*.douyin.com/*` 页面，不会在其他网站运行。
